## Basic Commands
* `sudo -i` It change the current user to root user 
* `uname -a` Which OS Is it 
* `ctl+l` Clear the shell or `clear`
* `ctl+d` Exit the Shell
* `ps` which cmd is working like *bash*
* `cd -` It goes to previous Directory
* `cd ~` It goes to directly into the home directory
